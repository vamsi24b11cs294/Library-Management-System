##### **1. Abstract**

##### 

**Customer Segmentation using Clustering is a Machine Learning project that groups customers into different segments based on their similarities in purchasing behavior. In this project, the K-Means Clustering algorithm is used to segment customers based primarily on Annual Income and Spending Score. The dataset is analyzed, preprocessed, scaled, and divided into clusters. The Elbow Method is used to determine a suitable number of clusters, while the Silhouette Score is used to evaluate the quality of the clustering. The resulting customer segments can help businesses understand customer behavior and develop targeted marketing strategies. The project uses Python and libraries such as Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn**



###### **2. Introduction**



**In modern businesses, customers have different purchasing habits, income levels, and preferences. Treating all customers in the same way may not be effective. Customer segmentation helps businesses divide customers into meaningful groups so that appropriate marketing strategies can be applied to each group.**



**Clustering is an unsupervised Machine Learning technique in which data points are grouped according to their similarities. In this project, K-Means Clustering is used to group customers according to their annual income and spending score.**



**The resulting clusters can represent different types of customers, such as high-income/high-spending customers or low-income/low-spending customers.**



###### **3. Problem Statement**



**Businesses often have a large number of customers with different characteristics. It can be difficult to manually identify customer groups and understand their behavior.**



**Therefore, the problem is:**



**To develop a Machine Learning system that automatically groups customers into meaningful segments based on their income and spending behavior using K-Means Clustering.**



###### **4. Objectives**



**The main objectives of this project are:**



**To understand customer purchasing behavior.**

**To select suitable features for clustering.**

**To determine an appropriate number of clusters using the Elbow Method.**

**To apply the K-Means Clustering algorithm.**

**To evaluate the clustering using the Silhouette Score.**

**To visualize the resulting customer segments.**

**To interpret the characteristics of each customer group.**

**To save the final customer segmentation results for further analysis.**
